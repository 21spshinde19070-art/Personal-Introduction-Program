Personal Introduction Project
Project Overview

This project is a simple Python application that displays a personal introduction. It was created to practice Python basics, understand how to use PyCharm as an IDE, and learn how to properly structure and document a project for GitHub submission.

The project demonstrates basic Python execution, project setup, and documentation standards.

Setup Instructions
Prerequisites

Python 3 installed on the system

PyCharm IDE installed

Installation and Execution

Install Python on your computer.

Install PyCharm (Community or Professional).

Open PyCharm and select Open Project.

Choose the project folder.

Configure the Python interpreter:

Go to File → Settings → Python Interpreter

Select the installed Python version

(Optional) Install dependencies:

pip install -r requirements.txt


Run the program:

Right-click on personal_intro.py

Click Run
